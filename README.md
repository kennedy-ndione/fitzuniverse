# FitzUniverse - Automated EdTech Platform for Scholarship Guidance

Welcome to **FitzUniverse**, an AI-driven, automated orientation platform designed to bridge the information gap for African students seeking scholarship and pre-enrollment opportunities abroad.

Live Platform: [https://fitzuniverse.com](https://fitzuniverse.com)

## 🚀 The Vision & Project Scope
Coming from an unconventional background, I built and launched this fully functional web platform end-to-end in **less than 4 months**. This project serves as a showcase of my ability to leverage cutting-edge Large Language Models (LLMs) alongside core web standards to ship complex user-centric products with extreme velocity.

## 🛠️ Tech Stack & Architecture
To ensure high speed, efficiency, and deep understanding of web fundamentals, this project is built entirely on native web technologies:
* **Frontend:** Semantic HTML5, Responsive CSS3 (Custom grid & flexible layouts)
* **Logic & Engine:** Vanilla JavaScript (ES6+) for the dynamic diagnostic algorithms, profile evaluation, and interactive student dashboard.
* **Paradigm:** AI-driven agile development (Vibe Coding with Claude) — engineered through advanced prompt structures to deliver production-ready code quickly.

## 💡 Key Features
* **Automated Diagnostic Tool:** A 5-minute interactive questionnaire analyzing user profile match for various countries and grants.
* **Country Procedures Tracker:** Step-by-step interactive workflow covering 9 destination countries (France, Canada, Morocco, etc.).
* **Dynamic Content Delivery:** Free, sourced, and up-to-date repository of active scholarship timelines.

## 🤖 AI-Driven Methodology & Learnings
Building this platform taught me how to operate as a **Product Engineer**. Instead of spending weeks on boilerplate code, I utilized generative AI to:
1. Model the database architecture and matching algorithms.
2. Rapidly debug structural and interface discrepancies.
3. Optimize the frontend performance for low-bandwidth mobile connections across West Africa.

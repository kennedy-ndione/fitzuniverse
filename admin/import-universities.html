Import universités (données codées en dur)

Écrase la collection Firestore universities avec le tableau codé en dur dans import-universities.js. Réservé aux administrateurs, non lié dans la navigation.

Action irréversible : chaque université du tableau est écrite via setDoc, ce qui écrase silencieusement tout document existant avec le même identifiant. Vérifie le contenu du script avant de lancer.

# La passe Études en France — guide de relevé

**But :** confirmer les 3 étapes marquées « à confirmer » dans
`js/procedures/france-senegal.js` — la **saisie**, les **pièces**, les **vœux**.
Une seule fois. Ensuite la France passe en « procédure documentée ».

**Ce que je ne peux pas faire à ta place :** tout ce qui suit est derrière
l'authentification. Ce guide ne te dit pas sur quel bouton cliquer — l'interface
change — il te dit **quelle information rapporter**.

---

## Avant de commencer

- Un compte sur **pastel.diplomatie.gouv.fr/etudesenfrance** (ton propre compte,
  ta vraie identité — c'est une plateforme d'État, jamais de fausse identité)
- Ton passeport et un diplôme sous la main : certains champs bloquent sans eux
- L'outil de capture de Windows (**Win + Maj + S**)
- Un dossier sur ton ordinateur : `campus-france-passe/`
- **Compte 1 h 30 à 2 h.** Ne le fais pas en quinze minutes entre deux choses.

**Si la campagne 2027-28 n'est pas encore ouverte** (elle ouvre vers le
1er octobre) : la création de compte et la structure du dossier restent en
général accessibles. Les vœux, eux, attendront. Fais ce que tu peux
maintenant, reviens pour les vœux.

**Règle de sécurité :** ne capture jamais un écran contenant ton numéro de
passeport ou ta pièce d'identité en entier. Masque-les. Ce qui nous intéresse,
ce sont les **libellés, formats et contraintes** — pas tes données.

---

## ÉTAPE 1 — La saisie du dossier

Tu cherches à répondre à : **de quoi le dossier est-il fait, section par
section, et où ça coince ?**

Pour CHAQUE section du dossier (informations personnelles, parcours scolaire,
parcours professionnel, compétences linguistiques, projet d'études…) :

- [ ] Le **nom exact** de la section, tel qu'écrit à l'écran
- [ ] Les champs **obligatoires** (souvent marqués d'une étoile)
- [ ] Tout champ qui **refuse** une saisie et le message d'erreur affiché
- [ ] Tout champ qui exige un **format précis** (date, notation, moyenne sur 20)
- [ ] Ce qui bloque le passage à la section suivante
- [ ] Une **capture** de chaque section

**Note aussi ce qui surprend.** Un ordre inattendu, un champ dont on ne comprend
pas ce qu'il demande, une section qu'on croyait facultative et qui ne l'est pas.
C'est exactement ce qu'un étudiant seul découvre trop tard.

## ÉTAPE 2 — Les pièces

C'est **la plus importante des trois**. Le tableau ci-dessous est la forme
exacte que le code attend.

Pour chaque pièce demandée, va jusqu'à l'écran de téléversement : les
contraintes y sont presque toujours écrites.

| Pièce (libellé exact) | Format(s) | Taille max | Traduction assermentée ? | Légalisation / apostille ? | Obligatoire ? |
|---|---|---|---|---|---|
|  |  |  |  |  |  |
|  |  |  |  |  |  |
|  |  |  |  |  |  |
|  |  |  |  |  |  |
|  |  |  |  |  |  |

**À ne pas rater :**

- [ ] Le message affiché quand un fichier est **trop lourd** ou **au mauvais
      format** — mot pour mot
- [ ] Une pièce doit-elle être **recto-verso en un seul fichier** ?
- [ ] Un **original papier** est-il réclamé quelque part, en plus du scan ?
- [ ] La traduction doit-elle être faite par un traducteur **agréé au Sénégal**,
      ou n'importe lequel ?
- [ ] Y a-t-il une pièce **spécifique au Sénégal** qui n'apparaît pas dans les
      guides généraux ?
- [ ] Une **capture de l'écran de téléversement**, où les contraintes sont
      visibles

Si une contrainte n'est écrite nulle part : écris **« non indiqué »**. Ne
devine pas. « Non indiqué » est une réponse valable, une supposition non.

---

## ÉTAPE 3 — Les vœux

- [ ] Le nombre maximum de vœux — **7 par niveau** d'après les sources
      publiques : **est-ce ce que l'écran affiche ?**
- [ ] Peut-on mélanger des niveaux (licence et master) dans un même dossier ?
- [ ] Comment les formations sont-elles cherchées : par établissement, par
      discipline, par ville ?
- [ ] Une formation peut-elle être **« non connectée »** ? Comment est-ce
      signalé, et que doit faire l'étudiant dans ce cas ?
- [ ] Les vœux sont-ils **ordonnés par préférence**, ou tous égaux ?
- [ ] Peut-on modifier ses vœux **après** avoir rempli le dossier, et jusqu'à
      quand ?
- [ ] Une **capture** de l'écran de recherche et de l'écran récapitulatif

**Le test décisif :** cherche « **Université de Bordeaux** ». Elle est dans ton
catalogue avec 6 programmes. Est-elle trouvable ? Sous quel nom exact ?
Si le nom de la plateforme diffère du tien, c'est une correction de catalogue.

## L'ARRÊT

**Ne soumets pas le dossier.** La soumission déclenche la demande de paiement
des 85 000 F et engage la procédure. Tout ce qui vient après est déjà documenté
depuis les sources publiques.

Note quand même, sans cliquer :

- [ ] Le libellé exact du bouton de soumission
- [ ] Ce que la plateforme annonce **juste avant** — le récapitulatif, l'avertissement
- [ ] Ce qu'elle dit qu'il se passera ensuite

## Ce que tu me renvoies

1. **Le tableau des pièces**, rempli — même partiellement
2. **Tes captures** (Étape 1, 2, 3), envoyées dans la conversation
3. **La date du jour** où tu as fait la passe — chaque fait doit porter sa date
4. **Ce qui t'a surpris**, en vrac. Le désordre est acceptable, l'invention non.

Je lis les captures, j'écris le correctif, et Claude Code fait passer les trois
étapes en « verifie_source_officielle ». La carte France passera d'elle-même en
« procédure documentée ».

## Si tu préfères ne pas la faire toi-même

Ton premier vrai étudiant peut t'envoyer ses captures à chaque étape. C'est même
mieux : tu verras ce qu'il voit, avec ses hésitations et ses erreurs — ce qu'un
regard entraîné ne remarque plus. Le relevé est le même ; seul l'auteur change.
